# Easy — конструктор здорового харчування

Веб-застосунок (PWA) нутриціолога **Олени Гаврилової**: людина обирає калорійність, збирає збалансовану тарілку з того, що є вдома, відмічає з'їдене й дивиться уроки. Власниця продукту — Олександра.

## Документи (читати перед змінами)
- `docs/TZ.md` — ТЗ: стек, дані, логіка, екрани, етапи.
- `docs/METHODOLOGY.md` — методика Олени і всі продуктові рішення.
- Дизайн-система: https://claude.ai/artifact/8JbhhLwjXXhbpYe1P1mtFU — CSS у `styles/components.css` (класи `ez-*`) і `styles/tokens.css` згенеровані з неї. Нові екрани будувати з цих класів; кольори й розміри — лише через токени.

## Дані
- `data/easy-tree.json` — дерево конструктора з дошки Олени: 4 калорійності × сніданок / обід / вечеря, гілки, кроки, варіанти з грамовками. **`label` — джерело істини**: грамовки не змінювати й не «округлювати». Поля `needs_review` — місця, які перевіряє Олена.
- `npm run check-tree` — перевірка цілісності дерева після будь-якої зміни JSON.

## Правила продукту (не порушувати)
- Калорійність — з таблиці Олени (`lib/calories.ts`), **вагу не питаємо**. Вік 18–50; молодше 18 — не рахуємо.
- **Калорій окремих тарілок не показуємо.** Крупи й макарони — суха вага + «≈ N г готової» (`cookedHint` у `lib/tree.ts`).
- Мова інтерфейсу — українська. **«Ти» ніде не використовуємо**: інтерфейс безособово («Зберегти», «З'їдено»), слова Олени (поради, уроки, нагадування) — на «ви».
- Дисклеймер незмінний (`components/Tip.tsx`).
- Акценти: бордовий — дія й поточне, оливковий — виконане.

## Структура
- `app/` — екрани: `/welcome`, `/onboarding`, `/result`, `/` (головна), `/build/[meal]` (конструктор), `/plate/[id]`, `/history`, `/learn`, `/profile`.
- `lib/tree.ts` — доступ до дерева, відображення варіантів, коефіцієнти. `lib/store.ts` — дані користувача (етап 1: localStorage; етап 2: Supabase, ті самі хуки). `lib/hints.ts` — поради Олени з уроків. `lib/lessons.ts` — уроки й гайди; відео — Vimeo (`vimeo: "id/hash"`, плеєр на `/learn`); PDF-гайди — `public/guides/`.
- `lib/photos.ts` — фото продуктів для карток: назва варіанта → `public/products/<slug>.webp`. Новий файл фото додати також у `AVAILABLE`. Без фото картка показує літеру. Шапка конструктора — `public/images/hero-<meal>.webp` (`buildHero`).
- `components/` — TabBar, Icon, Tip/Disclaimer, Guard.

## Команди
`npm run dev` · `npm run build` · `npm run check-tree`
