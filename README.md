# Easy

Конструктор здорового харчування нутриціолога Олени Гаврилової — веб-застосунок для телефона.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run check-tree # перевірка даних конструктора
npm run lint       # перевірка коду (запускається й під час build)
npm test           # автотести логіки
```

Технічна довідка — `docs/TECH.md`. Деталі для розробки — у `CLAUDE.md` і `docs/`.
