## 3. Потом — не MVP

### 3.1 Активность
- **Вкладка «Активність»** в нижнем меню: трекер на неделю (прогулки 20 хв ×3, 2 тренування, кроки…), отметки «було/не було», возможность добавить свою активность. Если регулярно срывается — совет перепройти анкету / выбрать другой уровень.
- Порады по активности и напоминания («сьогодні йдіть у магазин, який далі від дому»).
- Сначала — детальное видение Олены и моё, потом делаем один раз.

### 3.2 Самочувствие и история
- Трекер самочувствия после еды, лёгкая геймификация, чтобы хотелось заходить.
- Показ в «Історії»: самочувствие, шаги за день.
- **Вес не трекаем** (риск РПП) — решение.

### 3.3 Профиль
- Фото профиля (по умолчанию котик/маскот, можно загрузить своё).
- Пара/семья: каждый ставит приложение на свой телефон, подписка на двоих дешевле, чем две отдельные (общий профиль не делаем).

### 3.4 ИИ
- **«Задати питання» с ИИ:** отвечает по базе знаний Олены (уроки, созвоны); если ответа нет — вопрос Олене в Telegram, её ответ пополняет базу.
- **Рецепт по кнопке** «Підказати, що приготувати» — генерация Claude по правилам Олены, с кешем (этап 3 ТЗ).
- **ИИ-фото тарелки** с кешем по комбинациям: первая генерация до ~20 с, повтор — из базы. Оценка ≈ $20 на текущие комбинации. Решить: генерируем / коллаж / без картинки.
- ИИ-оценка средней калорийности блюда «поза конструктором».

### 3.5 Готовые рецепты «від Олени»
- При выборе приёма пищи: «Готова страва» или «Зібрати в конструкторі».
- База сбалансированных рецептов (50+ на старте): супы (борщ, гарбузовий), плов, паста (с креветками, болоньезе, «паста з тіктоку» с фетой), кабачковая пицца и т. п. Рецепт всегда на 1 порцию (+ «помножте на кількість порцій»); для больших блюд — сколько грамм положить на тарелку под свою калорийность и КБЖВ.
- Пополнять постепенно; новые рецепты — повод продлить подписку.

### 3.6 Правило 80/20
- Трекер «їжа поза конструктором» (напр. 2 рази на тиждень в кафе — оберіть улюблену страву).
- Урок/дополнение к уроку: «корисні / нейтральні / шкідливі інгредієнти» (піца, суші — ок; трансжири, модифікований крохмаль, глюкозно-фруктозний сироп, фритюр — уникати). **[Олена]** записать.

### 3.7 Расширение аудитории
- Версия для тех, кто не худеет, а хочет здорово питаться и «перестати думати, що приготувати на обід»: готовые рецепты + конструктор из того, что есть дома.

### 3.8 Маркетинг
- Позиционирование: «не записуєте, що з'їли, а плануєте раціон» — главный отличитель от трекеров калорий.
- Система продления подписки, анонсы обновлений.

### 3.9 Отложено / скорее не делаем
- Персонализация «не їм / алергени» — пока нет: варианты не обязательны, человек просто не выбирает (плов без нуту = рис).
- Нативное мобильное приложение — нет: сайт (PWA) обновляется у всех за минуты, без релизов в сторах.
