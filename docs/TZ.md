## 1. Что строим

**Easy — «Конструктор здорового харчування» Олени Гаврилової.** Это веб-приложение для телефона (PWA, ставится на экран как приложение), его можно открыть и на компьютере.

**Что делает человек в приложении:**
1. Проходит анкету и получает свою калорийность (одну из 4 веток).
2. Собирает сніданок, обід или вечерю по шагам. Порции заранее посчитаны Оленой.
3. Получает тарелку с граммами и рецепт.
4. Отмечает «З'їдено», ведёт историю, сохраняет любимые блюда.
5. Смотрит 12 видеоуроков и читает гайды.
6. Платит за подписку: 1 / 3 / 6 месяцев или «назавжди».

**Язык и тон:**
- Интерфейс на украинском. Все тексты лежат в файлах переводов, чтобы позже добавить другие языки.
- «Ти» не используем. Интерфейс безличный («Зберегти», «З'їдено»), слова Олены — на «ви».

## 3. Данные (таблицы)

**Справочники Олены:**
- `levels` — 4 калорийности: `1600-1650`, `1700-1750`, `1800-1850`, `2000`.
- `constructor_options` — дерево из `easy-tree.json`: приём пищи → калорийность → ветка → шаг → варианты.
  - Поле `label` — источник истины.
  - `amount`, `unit`, `oil_ml` — разобранная граммовка, составные варианты (`composite`) нужно разобрать вручную.
  - `needs_review` — места, которые проверяет Олена.
- `products` — продукт, фото, название по языкам. Варианты дерева ссылаются на продукт.
- `cooking_coefficients` — коэффициенты «сухой → готовый»: гречка ×2,5, пшоно ×3, булгур ×2,5, кіноа ×3, рис бурий ×2,7, рис білий ×3, макарони ×2,3, цільнозернові ×2,5, вівсянка ×3, перлова ×3, ячна ×3.
- `hints` — подсказки Олены: контекст (шаг / приём пищи / напоминание), текст, ссылка на урок.
- `lessons` — блок, порядок, название, видео-id, длительность. `guides` — PDF.

**Данные пользователя:**
- `profiles`: имя, пол, возраст, рост, активность, калорийность (вычисляется, можно перепройти анкету), время подъёма и сна, язык.
- `plates`: пользователь, дата, приём пищи, калорийность, выбранные варианты (json), статус `planned` / `eaten`, избранное, recipe_id.
- `recipes`: хэш набора продуктов → текст рецепта (кэш ИИ), отметка «рецепт не вдався».
- `lesson_progress`.
- `subscriptions`: тариф, статус, `current_period_end`, промокод. `payments`.

**Профили семьи:** позже, на старте один профиль на аккаунт.

## 4. Логика

### 4.1 Калорийность (без веса)

| Пол | Рост | Базовая активность | Средняя активность |
|---|---|---|---|
| Женщина | 160–170 (и ниже 160) | 1600-1650 | 1700-1750 |
| Женщина | 170–180 (и выше 180) | 1700-1750 | 1800-1850 |
| Мужчина | 170–185 (и вне диапазона) | 1800-1850 | 2000 |

**Уровни активности:**
- **базовая:** ≈ 7 000 шагов в день + 1–2 тренировки в неделю;
- **средняя:** 10–12 тыс. шагов в день + 3 тренировки с весом.

**Возраст:**
- 18–50 лет;
- **младше 18** — калорийность не считаем, советуем специалиста;
- старше 50 — отдельной логики нет.

**Прочее:**
- все калорийности рассчитаны на снижение веса;
- сменить калорийность можно в профиле, повторно пройдя анкету.

### 4.2 Конструктор

Шаги идут строго по дереву:
- **Сніданок:** Основа → Яйця (2 шт / 1 / без) → Білок → Сир (включая йогурт) → Овочі 150 г → Фрукти.
  - В ветках «1 яйце» и «без яєць» последний шаг — протеиновый йогурт или батончик.
  - Млинці → білок → сир → овочі → фрукти. Панкейки → сир → фрукти. Галета → йогурт → фрукти.
- **Обід:** Гарнір (крупи / макарони / картопля-бобові) → Білок (м'ясо / риба / морепродукти) → Сир → Овочі 150 г → Фрукти → шоколад 10 г через день.
- **Вечеря:** Гарнір → Білок → Овочі 150–200 г.

**Правила отображения:**
- Варианты берутся из ветки текущей калорийности и показываются карточками с фото и граммовкой.
- У круп и макарон вес сухой, рядом «≈ N г готової» по коэффициенту.
- Если рядом с продуктом «+5 мл олії», показываем подсказку: «жир можна взяти олією, вершковим маслом, авокадо чи горіхами».
- Кнопка **«Нічого з цього немає вдома»** на MVP показывает остальные варианты этого же шага и подсказку. Позже — умные замены.
- Можно вернуться на любой пройденный шаг, выбор сохраняется.

**Итог:**
- Тарелка: список с граммами, без ккал.
- Действия: «Рецепт», «Зберегти страву», «З'їдено», «В улюблені».

### 4.3 ИИ-рецепт

Сервер отправляет Claude продукты с граммовками и жёсткие правила:
- только эти продукты; можно добавить специи, зелень, лимонный сок и воду;
- граммы не менять, масла не больше указанного;
- только способы приготовления Олены: рыба до 160 °C, мясо до 170 °C, крупы промыть и замочить, яйца на ≤ 5 мл масла;
- 3–6 шагов, на «ви».

Ответ сохраняем в `recipes`, одинаковый набор продуктов отдаём из кэша. Кнопка «рецепт не вдався» удаляет рецепт из кэша.

### 4.4 Напоминания

Время берём из анкеты (подъём и сон), правила — из урока 3.4:
- «Час снідати» — через 30–60 мин после подъёма;
- «Час обідати» — через 4 ч после завтрака;
- «Вечеря» — за 2–3 ч до сна;
- раз в 2–3 дня — «Перевірте холодильник / список покупок».

Человек выбирает, какие напоминания получать.

### 4.5 Доступ

- **Без подписки:** анкета, просмотр одного примера тарелки и вступительного видео.
- **С активной подпиской:** всё остальное. Проверка на сервере.
- После окончания периода доступ закрывается автоматически.
- Промокоды: бета-группа на 3 недели, семейная скидка.

## 5. Экраны (компоненты — из дизайн-системы)

1. **Вход / приветствие** — маскот или фото, «Почати», вход по email-коду.
2. **Анкета** — пол, возраст, рост, активность, время подъёма и сна. Компонент ChoiceField.
3. **Результат** — «Ваша норма 1700–1750 ккал» и пояснения из гайда.
4. **Головна:**
   - ScreenHeader «Доброго ранку!» + PlanCard «1 з 3 прийомів»;
   - MealCard × 3 (собранный — с фото, пустой — «Зібрати тарілку»);
   - FavoriteCard;
   - «Порада Олени».
5. **Конструктор** — фото приёма пищи, StepProgress, сетка ProductCard, «Назад» / «Продовжити», подсказки на шагах.
6. **Страва / тарелка** — DishHero, PlateSummary, RecipeSteps, кнопки.
7. **Історія** — DayStrip, HistoryRow со StatusChip, RepeatCard.
8. **Навчання** — 4 блока уроков с прогрессом, гайды PDF.
9. **Профіль** — данные, калорийность («змінити»), напоминания, подписка, дисклеймер.
10. **Оплата** — TariffCard × 4, «Оплатити», дисклеймер.
11. **Админка** (только Олександра и Олена) — продукты и фото, варианты дерева, подсказки, уроки, цены, промокоды.

Нижнее меню: Головна · Моя тарілка · Історія · Навчання · Профіль.

## 6. Этапы

| Этап | Что входит | Готово, когда |
|---|---|---|
| **1. MVP-конструктор** | анкета, калорийность, конструктор по дереву, тарелка, история и избранное (локально), PWA, дизайн по системе | можно собрать любую тарелку на телефоне |
| **2. Аккаунты и доступ** | вход по email, данные в Supabase, подписки, оплата, промокоды | бета-группа заходит по промокоду |
| **3. Контент** | уроки (Bunny), гайды, подсказки Олены, ИИ-рецепты | весь контент внутри |
| **4. Удержание и админка** | напоминания, админка, фото продуктов | Олена сама правит контент |
